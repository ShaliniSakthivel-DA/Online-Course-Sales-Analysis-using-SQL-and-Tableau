# SQL & Tableau – Online Course Sales Dashboard

## Project Overview
This project presents an interactive sales dashboard created using SQL and Tableau to analyze online course sales performance, revenue trends, and customer insights through data visualization.

---

## Project Objective
The objective of this project is to:
- Analyze online course sales data
- Identify revenue trends and sales patterns
- Compare category-wise and country-wise performance
- Create interactive visualizations for better business insights

---

## Key Insights
- Revenue by Course
- Monthly Revenue Trends
- Country-wise Revenue Analysis
- Category-wise Revenue Distribution
- Learner and Sales Performance Analysis
